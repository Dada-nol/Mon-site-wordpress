# Mon Site WordPress Ce dépôt contient une version de WordPress prête à être installée et utilisée pour créer votre site web. --- ## Installation Rapide (en 5 minutes) 1. **Décompressez** l’archive dans un dossier vide de votre ordinateur. 2. **Modifiez** le fichier `wp-config-sample.php` avec les informations de connexion à votre base de données. 3. **Renommez** le fichier en `wp-config.php`. 4. **Envoyez** tous les fichiers sur votre hébergeur via FTP. 5. **Lancez** l’installation en ouvrant `wp-admin/install.php` dans votre navigateur. > Si l'installation échoue, éditez manuellement `wp-config.php` et entrez les bonnes informations de base de données. --- ## Connexion Après installation : - Identifiant : `admin` (par défaut) - Mot de passe : généré automatiquement (notez-le) Connectez-vous via [wp-login.php](wp-login.php) pour administrer votre site. --- ## Mise à jour ### Automatique (WordPress ≥ 2.7) - Rendez-vous sur `wp-admin/update-core.php` et suivez les instructions. ### Manuelle (versions < 2.7) 1. Sauvegardez tous vos fichiers personnalisés. 2. Supprimez les anciens fichiers sauf `wp-config.php` et `/wp-content/`. 3. Téléversez les nouveaux fichiers WordPress. 4. Ouvrez `wp-admin/upgrade.php` dans votre navigateur. --- ## Migration depuis d'autres plateformes WordPress peut importer du contenu depuis d'autres outils : - Installez WordPress - Utilisez l’outil [d'import](wp-admin/import.php) --- ## Prérequis techniques - PHP ≥ **7.0** - MySQL ≥ **5.0** ### Recommandé : - PHP ≥ **7.4** - MySQL ≥ **5.6** - Module Apache `mod_rewrite` - Prise en charge de **HTTPS** - Un lien vers [wordpress.org](https://fr.wordpress.org/) --- ## Ressources utiles - [Documentation officielle (HelpHub)](https://fr.wordpress.org/support/) - [Actualités WordPress](https://wordpress.org/news/) - [Planet WordPress (en)](https://planet.wordpress.org/) - [Forum francophone](http://wpfr.net/support/) - [Canal IRC WordPress](https://codex.wordpress.org/IRC) --- ## Pour les développeurs WordPress dispose d'une API robuste : - [Créer une extension](https://developer.wordpress.org/plugins/) --- ## Participer Vous aimez WordPress ?
